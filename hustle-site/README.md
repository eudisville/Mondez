# Hustle site (React + CSS pur)

```bash
npm install
npm run dev      # développement
npm run build    # production (dossier dist/)
```

- Projets du portfolio : `src/projects.js`
- Textes et sections : `src/App.jsx`
- Styles : `src/styles.css`
- Images : place-les dans `public/` et référence-les avec `/nom-du-fichier.jpg`
